# AI Video Editor - Master Build Prompt

## Product Vision

**ONE SOURCE VIDEO → FULL UNDERSTANDING → BEST MOMENTS → HIGH-ENERGY SHORTS → ORIGINAL COMMENTARY → DYNAMIC CAPTIONS → PROFESSIONAL SOUND DESIGN → REFERENCE-STYLE EDITING → COHERENT LONG-FORM VIDEO → AUTOMATIC QUALITY CONTROL → WATERMARK-FREE EXPORT → READY TO PUBLISH**

## Core Philosophy

ANALYZE → UNDERSTAND → SELECT → PLAN → REWRITE → EDIT → RENDER → VERIFY → IMPROVE

## Key Features

### 1. Input System
- Upload File (MP4, MOV, MKV, WebM, AVI, M4V)
- Paste Video Link
- File validation, codec detection, proxy generation

### 2. Video Understanding
- Scene detection, face recognition, object detection
- Speech-to-text with word-level timestamps
- Speaker diarization
- Audio analysis (music, SFX, speech, silence)
- Semantic analysis (keywords, punchlines, story beats)

### 3. Viral Moment Radar
- Scores: Hook, Entertainment, Emotion, Humor, Surprise, Story Importance
- Replay Potential, Short-Form Potential, Long-Form Potential
- Explanation for each selection

### 4. Shorts Generator
- 9:16, 1080x1920, 30fps
- 15, 20, 30, 45, 60, 90 seconds + custom
- HOOK → CONTEXT → ESCALATION → PAYOFF → END/LOOP

### 5. Editing Engine
- Dynamic jump cuts, punch-in/out zoom
- AI subject/face tracking
- Speed ramps, freeze frames, replay
- Animated captions with keyword emphasis
- Context-aware SFX and music

### 6. Long-Form Builder
- 5-20+ minutes
- HOOK → SETUP → CONTEXT → STORY → ESCALATION → EVENTS → PAYOFF → CONCLUSION
- Chapter system with titles, timestamps, transitions

### 7. Quality Control
- Automated QC checks
- Self-critique and improvement
- Auto-fix and re-render

### 8. Export
- YouTube Shorts, Long-form, TikTok, Instagram Reels
- **NEVER adds app watermark**
- No platform branding

## Design Requirements
- Premium professional creative tool
- Dark theme primary
- Responsive for phone, tablet, desktop
- Fast workflows, visual clarity
- Professional timeline, intuitive AI controls
